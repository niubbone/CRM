💶 Formula Fiscale (Regime Ordinario)

S (subtotale) │ ├── quota = S × 4% (solo se applicaQuota=true — Cassa Previdenziale) │ imponibile = S + quota ritenuta = imponibile × 20% ← sempre applicata IVA = imponibile × 22% lordo = imponibile + IVA netto = lordo − ritenuta ← questo va in Importo_Totale su Sheets
Regola: Usare sempre calcolaFiscale(subtotale, applicaQuota) in crm_utils.js. Non calcolare IVA/ritenuta manualmente in nessun altro file. 
// crm_utils.js
const f = calcolaFiscale(1000, false);
// → { subtotale:1000, quota:0, imponibile:1000, ritenuta:200, iva:220, lordo:1220, netto:1020 }

const f2 = calcolaFiscale(1000, true);
// → { subtotale:1000, quota:40, imponibile:1040, ritenuta:208, iva:228.80, lordo:1268.80, netto:1060.80 }

📋 Google Sheets — Struttura Colonne

Le colonne qui sotto rispecchiano l'ordine reale in ogni foglio. Gli indici (0-based) sono usati nei COLS object del backend.

Clienti (A–P, 16 col):
A=ID_Cliente | B=Nome_Cliente | C=Indirizzo | D=CAP | E=Città | F=P.IVA | G=CF
H=SDI | I=Email | J=Referente | K=ATTIVO | L=Titolo | M=Cellulare | N=Tel. | O=NOTE | P=WKI

Timesheet (A–S, 19 col):
A=ID_Intervento | B=ID_Cliente | C=Nome_Cliente | D=DATA | E=START | F=STOP
G=Tipo_Intervento | H=Mod_Esecuzione | I=Durata_Ore | J=Chiamata | K=Mod_Addebito
L=ID_Pacchetto | M=EXTRA | N=Descrizione | O=Costo | P=Variazioni | Q=Costo_Finale
R=N_Proforma | S=N_Fattura

Pacchetti (A–L, 12 col):
A=ID_Pacchetto | B=ID_Cliente | C=Nome_Cliente | D=Data_Acquisto | E=Data_Scadenza
F=Descrizione | G=Ore_Acquistate | H=Ore_Utilizzate | I=Ore_Residue | J=STATO | K=Importo | L=Costo_Orario

Proforma (A–M, 13 col):
A=N_Proforma | B=Data_Emissione | C=ID_Cliente | D=Nome_Cliente | E=Importo_Subtotale
F=Quota_4% | G=Importo_Totale (=netto) | H=Causale | I=N_Fattura | J=Data_Fattura
K=Pagato | L=PDF_FileID | M=Ore_Pacchetto
⚠️ N_Proforma formato "M/YYYY" viene interpretato come Date da Sheets — sempre gestire con Date-aware check

Fatture (A–M, 13 col):
A=N_Fattura | B=Data_Fattura | C=ID_Cliente | D=Nome_Cliente | E=Imponibile (=S+quota)
F=IVA_22 | G=Importo_Totale (=netto = lordo−ritenuta) | H=Descrizione | I=N_Proforma
J=Pagato | K=Data_Pagamento | L=Note | M=Ritenuta
ℹ️ I=N_Proforma può essere una lista CSV ("1/2026, 2/2026") per fatture multi-proforma

Canoni (A–L, 12 col):
A=ID_Canone | B=ID_Precedente | C=ID_Cliente | D=Nome_Cliente | E=Descrizione
F=Data_Inizio | G=Data_Scadenza | H=Importo | I=STATO | J=Data_Fattura | K=N_Fattura | L=Event_ID
(+ colonna Fatturazione per stato ciclo proforma)

Firme (A–M, 13 col):
A=ID_Firma | B=ID_Precedente | C=ID_Cliente | D=Nome_Cliente | E=Tipo | F=Data_Inizio
G=Data_Scadenza (+3 anni) | H=Importo | I=STATO | J=Acquisto | K=N_Fattura | L=Event_ID | M=Note

RIF (config):
L2 = ultimo numero proforma | M2 = anno corrente proforma

Log:
A=Timestamp | B=Level | C=Action | D=Message | E=User | F=Data (JSON)

Insert pattern (backend .gs) 
function insertAlgo(params) {
  try {
    const validation = validateClient(params.cliente);
    if (!validation.valid) return { success:false, error:validation.error };

    const sheet = getSpreadsheet().getSheetByName('Foglio');
    const row = [params.campo1, params.campo2, new Date()];
    sheet.getRange(sheet.getLastRow()+1, 1, 1, row.length).setValues([row]);
    SpreadsheetApp.flush();

    writeLog('INFO', 'INSERT_X', 'Inserito ' + params.campo1, {});
    return { success: true };
  } catch(err) {
    Logger.log('ERRORE: ' + err.message);
    return { success: false, error: err.message };
  }
}
