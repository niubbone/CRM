🎯 Overview Progetto

CRM Studio Smart è un sistema completo di gestione clienti progettato per studi legali e professionali. Integra timesheet, fatturazione, pacchetti ore, gestione scadenze e molto altro in un'unica applicazione web moderna, performante e offline-capable.

Il sistema è stato progettato per massimizzare efficienza e usabilità, con particolare attenzione a:

  • 🚀 Performance: Cache intelligente (+70% velocità), micro-caching backend
  • 📱 Mobile-first: PWA installabile, funziona offline
  • 🔒 Data integrity: Validazione robusta, sistema log completo
  • ⚡ Zero server cost: GitHub Pages + Google Apps Script
  • 🔄 Real-time sync: Google Sheets come database cloud
~9.000 Righe di Codice

🔄 Data Flow Esempio

ESEMPIO: Inserimento Nuovo Cliente

1. UTENTE
   └─> Compila form cliente (nome, email, telefono)
   └─> Click "Salva Cliente"

2. FRONTEND (clienti.js)
   └─> Valida input (email format, campi required)
   └─> showLoadingState()
   └─> fetch(`${API_URL}?action=insert_client&nome=...&email=...`)

3. BACKEND (Router.gs)
   └─> doGet(e) riceve request
   └─> switch(e.parameter.action)
   └─> case 'insert_client': return insertClient(e.parameter)

4. BUSINESS LOGIC (Clienti.gs)
   └─> insertClient(params)
       ├─> validateClientData(params) // check email duplicati
       ├─> generateClientID() // C_2025_001
       ├─> getSpreadsheet().getSheetByName('Clienti')
       ├─> appendRow([id, nome, email, tel, ...])
       ├─> writeLog('SUCCESS', 'INSERT_CLIENT', ...)
       ├─> invalidateCacheClienti() // cache refresh
       └─> return {success: true, clientId: "C_2025_001"}

5. FRONTEND RESPONSE
   └─> result = await response.json()
   └─> if (result.success):
       ├─> updateClientsList() // reload lista
       ├─> closeModal('client-modal')
       ├─> showSuccessMessage("Cliente creato!")
       └─> window.clients.push(newClient) // update cache

6. GOOGLE SHEETS
   └─> Nuova riga in foglio "Clienti"
   └─> Trigger formule automatiche (es: COUNTIF per stats)
   └─> Data disponibile immediatamente per altre funzioni

🔒 Security & Data Integrity

🔐 HTTPS Only: GitHub Pages (SSL) + Apps Script (SSL), no mixed content
🔐 Input Validation: Frontend (UI) + Backend (business logic), double layer
🔐 Email Validation: Regex pattern + domain verification, deduplicazione
🔐 SQL Injection: N/A (Google Sheets, no SQL queries)
🔐 XSS Protection: No innerHTML con user input, sanitization layer
🔐 Data Backup: Google Sheets native versioning (30 giorni history)
🔐 Audit Log: Tutte operazioni CRUD logged con timestamp + user
🔐 Access Control: Apps Script deployed "as user" (OAuth Google)
